Drag
Vertical for knobs and steppers (200px = full range). Along the track for sliders. Relative, never jumps.
Shift
Fine adjust: one tenth the speed. Change mid-drag without a jump.
Wheel
1% per notch, 0.2% with Shift. Hover is enough; no focus needed.
Double-click
Reset to the default tick.
Keys
Arrows 1%, Shift+Arrows 0.1%, PgUp/PgDn 10%, Home/End.
Readout
Floating value chip while dragging. Label value turns accent.
