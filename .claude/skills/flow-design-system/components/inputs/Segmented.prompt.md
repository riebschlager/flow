Pick one of 2–7 discrete musical values (note rate, chord length, octaves, rhythm speed). Replaces short selects.

```jsx
<Segmented defaultValue={8} options={[{ value: 4, label: '4 beats' }, { value: 8, label: '8 beats' }, { value: 16, label: '16 beats' }]} />
```

- `full` stretches to the container.
