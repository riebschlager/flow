# Retired: Drift and Wander harmony

Removed November 1, 2026. This roadmap item is closed and is no longer part of the feature plan.

The idle performer, temporary related-progression selection, note interval controls, legacy preference loading, and generative long WAV source were removed together. Breathing guidance was subsequently removed as well. The sleep timer remains available in Play, Zen and Present. Long WAV exports repeat recorded sessions.

Existing recordings contain resolved notes, gestures and progression snapshots, so they retain replay, sharing, fork and export compatibility without either retired engine. Automatic droplets, manual gestures, progression choices, arpeggiation and percussion continue independently.
